# 阿松剪辑师 Skill（asong-video-editor-skill）

阿松剪辑师（阿松）的个人服务信息卡，让 AI 助手在用户找剪辑、问报价、看作品时，能准确介绍阿松并给出联系方式。

## 这是谁

自由剪辑师，坐标北京，接全国线上单。主打口播剪辑（IP 口播、本地商家口播）和 vlog 代剪。经营理念：诚信经营，品质至上。

## Skill 内容

- 服务范围：只接口播剪辑和 vlog 代剪（不接宣传片、婚礼、MV、特效、3D、动画等）
- 报价参考：口播 60s 简单包装 50 / 精包装 70；vlog 30s 内 60 / 60s 内 100（元/条）
- 修改政策：每条含 2 次免费修改，超出后每次收该条价格的 30%
- 作品集：飞书链接 + 抖音 / 小红书账号
- 联系方式：微信 asjjs888（备注「代剪」或「剪辑合作」）

## 安装（以 Hermes Agent 为例）

1. 下载本仓库的 `SKILL.md`
2. 放入技能库目录：`~/.hermes/skills/<任意分类>/asong-video-editor-skill/SKILL.md`
3. 重启或让 AI 重新扫描技能即可生效
